API de Tarefas

{% include "tarefas/theme_picker.html" %}

API REST para organizar tarefas pessoais. Cada usuário autenticado acessa somente as próprias tarefas.

Comece por aqui

  • Faça login em /api/login/ para obter um token.
  • Acesse /api/tarefas/ para listar ou criar tarefas.
  • Use ?concluida=true|false ou ?prioridade=baixa|media|alta para filtrar.
  • Envie o token no cabeçalho Authorization: Token <token>.
